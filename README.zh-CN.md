**面向 OpenAI Codex 与 ChatGPT 的开源 AI 深度阅读 Skill · 费曼学习 · 多角度辨析 · 情境化应用**

读一本书，真正耗时的往往不只是翻页，而是找不到重点、概念似懂非懂、观点照单全收，读完以后仍然不知道怎么用。

**AI Reading** 是一个面向 OpenAI Codex 和 ChatGPT 的开源 AI 阅读与书籍分析 Skill。它帮你快速找到真正值得追踪的问题，把复杂概念讲清楚，从多个角度辨析观点，再结合你的角色、目标和现实限制，把有价值的部分转化成行动和表达。

> 普通 AI 帮你更快得到一份摘要。AI Reading 帮你更快形成自己的理解和判断。

它压缩的是无效摸索和重复整理，而不是阅读本身的体验。

## 30 秒开始使用

打开 Codex，直接粘贴：

```text
使用 $skill-installer 从以下地址安装 AI Reading Skill：
https://github.com/yanz86808-beep/ai-reading-skill/tree/main/skills/ai-reading
```

安装成功后，新开一轮对话：

```text
使用 $ai-reading 阅读《思考，快与慢》，把全书结构、核心观点、争议和现实应用一次讲清楚。
```

Skill 本身不需要 API Key 或额外运行时依赖。需要核验当前事实或外部证据时，宿主可能需要联网搜索权限。

## 用 AI Reading 读书，会有什么不同

### 更快找到值得投入时间的问题

它不会把每一章、每一个概念都当成同等重要，而是从你的阅读目标出发，优先找到最值得理解的概念、最需要辨析的观点和最可能影响现实行动的问题。

### 先把书讲完整，再集中核验

宽泛地说“帮我读这本书”时，AI Reading 默认先把全书总框架作为第一核心知识点讲透：说清这本书要解决什么、有哪些关键模块、彼此如何运转与反馈。然后展开 3–5 个挂靠总框架的核心模块，每个模块都说明在整体中的位置，并用“背景—过程—结果—结论”讲透一个代表性书中案例；随后再给 3 个反常识案例、方法工具箱、3 条行动和简洁现实应用。证据强弱、过时风险与未核实内容集中放在末尾审计，不让免责声明切碎阅读正文。

### 形成自己的理解和判断

它会请你用自己的话解释复杂概念，发现那些“好像懂了、其实讲不清”的地方；也会从多个相互独立的角度辨析观点。目的不是为了反驳作者，而是理解一个观点为什么成立、在什么条件下成立，又可能在哪里失效。

### 把书放回你的现实情境

同一个观点，对管理者、教师、招聘负责人、内容创作者和普通读者，可能意味着完全不同的问题。AI Reading 只使用你明确提供的角色、目标、权限和限制，进一步判断：它对你意味着什么，哪些部分可以使用，哪些需要调整，哪些不能机械照搬。

## 默认完整报告，也支持四阶段引导

```text
找准问题 → 讲清概念 → 多角度辨析 → 回到现实
```

| 阶段 | 对读者的意义 | 实际会做什么 |
|---|---|---|
| **1. 找准问题** | 判断时间最值得花在哪里 | 确认书籍、阅读目标、材料范围、读者情境，以及最值得继续追踪的问题。 |
| **2. 讲清概念** | 把“我好像懂了”变成自己的解释 | 使用费曼法，一次处理一个概念，尝试讲到 6 岁孩子也能听懂，再纠偏、类比和重新复述。 |
| **3. 多角度辨析** | 不因为一个观点听起来有道理，就轻易把它当成答案 | 理解观点为什么成立、有哪些证据、依赖什么条件，以及它的适用边界在哪里。 |
| **4. 回到现实** | 把理解转化成可以使用的成果 | 生成一个真正相关的检查表、知识卡片、培训大纲、决策辅助或渠道内容。 |

四个阶段可以连续运行，也可以单独执行。你可以直接从第二、第三或第四阶段开始；AI Reading 只会补齐当前阶段所需的最小可信基础，不会强迫你重新跑完整流程。

如果你只说“帮我读一下”，默认一次性交付完整报告。如果你说“带我逐步读”“先从阶段一开始”，则进入互动引导；费曼阶段会等你亲自回答。

## 它为什么能节省时间

AI Reading 缩短的是从“接触到一本书”到“能够解释、判断和使用”的路径，主要减少四种低效过程：

1. **没有问题地阅读**：先找到与你目标最相关的问题，不把时间平均分给所有内容。
2. **把熟悉误当成理解**：通过解释、纠偏和复述暴露理解断点，减少反复被动阅读。
3. **接受观点却没有看见边界**：在一个结构化过程中完成多个独立角度的辨析。
4. **读完以后从头整理**：在阅读过程中就把洞察放进现实情境，并形成一个可用成果。

对于管理、心理学、商业、方法论和科普类书籍，它可以明显缩短通往“可用理解”的路径。对于文学作品，它会保留文本的多义性和阅读体验，不把“读得更快”当成唯一目标。

## “结合你的情境”到底是什么意思

AI Reading 不会给所有人生成同一份应用建议。它可以使用你明确提供的信息，例如：

- 你的角色，以及正在面对的决定；
- 你希望通过阅读解决的问题；
- 你能够影响和不能影响的范围；
- 组织、伦理、法律或现实限制；
- 最终需要形成的成果形式。

例如，“默认选项会影响人的选择”这个观点，对设计产品界面的产品经理、收集候选人数据的招聘负责人，以及希望改变习惯的个人，意味着完全不同的问题。AI Reading 调整的是阅读问题和应用边界，而不是篡改原书观点。

## 适合用来做什么

- 非虚构、管理、心理学、商业和方法类书籍
- 历史、传记、哲学和科普作品
- 文学、小说和多重文本解读
- 对用户合法提供的局部材料进行深度阅读
- 费曼学习、批判性阅读、决策辅助、读书笔记和内容资产制作

AI Reading 不要求你先上传整本书。根据要执行的阶段，书名、作者、ISBN、封面、一个概念、目录、合法节选或阅读问题，都可以成为起点。

<details>
<summary><strong>输入选项与材料条件</strong></summary>

| 输入 | 是否必需 | 说明 |
|---|---:|---|
| 书籍或概念 | 是 | 提供书名、作者、ISBN、封面或概念。身份有歧义时先确认作者或版本。 |
| 阅读目标 | 建议 | 理解概念、解决问题、研究论证、体验文学作品或制作内容资产。 |
| 当前阶段 | 否 | 未指定时默认生成完整阅读报告；也可直接指定阶段一至四。“下一阶段”会继承当前阅读状态。 |
| 原书材料 | 否 | 有条件时可提供合法节选、目录、章节或关键页。 |
| 读者情境 | 否 | 可提供角色、问题、行动范围和限制；不会推断敏感个人特征。 |
| 输出控制 | 否 | 可指定简版、标准版、深度版、是否剧透、目标渠道或资产类型。 |

每次输出都会说明实际材料覆盖范围：

- 已有任务所需原文时，以用户材料为主要依据。
- 只有公开资料时，优先使用作者、出版社、论文和权威机构等来源。
- 只有局部节选时，只对实际覆盖的片段作出结论。
- 冷门新书或身份无法核实时，会请求目录或合法节选，不根据标题或二手内容编造信息。

缺少用户粘贴的原文，本身不是阻塞条件。只有当书籍或目标无法识别，或者完全没有可靠材料支持当前阶段时，流程才会暂停询问。
</details>

<details>
<summary><strong>输出模式与阶段完成条件</strong></summary>

- **完整报告模式（宽泛请求的默认）**：一次提供作为第一核心知识点的全书总框架、3–5个挂靠其下且带详细案例的核心模块、3个反常识案例、方法工具箱、3条行动、费曼自测、压力测试、可信度审计和一个简洁现实应用。
- **引导模式**：用户明确要求逐阶段阅读时互动推进，费曼学习阶段会等待读者回答。
- **单阶段模式**：直接执行指定阶段，只补齐本阶段需要的最小可信基础。
- **专题报告模式**：围绕用户指定问题一次提供研究、自测材料、多角度辨析和资产建议，同时标明哪些互动尚未发生。
- **长度档位**：简版通常最多 3 个核心框架；标准版通常为 3–5 个；深度版增加争议、反例和来源比较。

第三阶段会根据观点复杂度选择不同数量的视角：简单方法通常使用 2 个，因果或外推主张通常使用 3 个，同时影响个人、组织、制度和伦理的高风险主张使用 4 个。每个视角必须真正不同，不能只是把同一个反对意见换一种说法。

跳过的阶段不会被写成已经完成。输出会区分可核验的原书内容、作者补充、第三方解读和分析推断。
</details>

## 可信阅读边界

可信是整个流程的基础，但不是吸引用户的口号：

- 不编造章节、案例、实验、数据、页码或引语
- 不输出可以替代原书的逐章重建或大量连续文本
- 只有局部材料时，不宣称已经完整覆盖全书
- 不根据读者情境推断敏感个人特征
- 不替代专业医疗、法律或金融意见

完整规则见 [`source-and-copyright-policy.md`](skills/ai-reading/references/source-and-copyright-policy.md)。

## 手动安装

克隆或下载仓库后，只复制 [`skills/ai-reading`](skills/ai-reading)：

```bash
git clone https://github.com/yanz86808-beep/ai-reading-skill.git
mkdir -p ~/.agents/skills
cp -R ai-reading-skill/skills/ai-reading ~/.agents/skills/ai-reading
```

部分环境使用 `$CODEX_HOME/skills`，通常为 `~/.codex/skills`；使用 `$skill-installer` 时会自动选择当前配置目录。需要仓库级发现时，将 Skill 目录复制到目标仓库的 `.agents/skills/ai-reading`。
