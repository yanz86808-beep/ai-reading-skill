# 内容资产模板

仅在用户进入资产转化并需要内容渠道输出时读取。默认只生成一个样稿，不自动铺满全部平台。

## 共通输入

生成前确认：

- 目标受众
- 具体问题
- 选用的一个核心观点
- 证据和边界
- 渠道及期望长度
- 用户自己的经历或立场（没有时不要代写个人经历）

## 知识卡片

```markdown
### [能表达价值的标题]
- 一句话观点：
- 证据：
- 怎么用：
- 不适用的情况：
- 来源：
```

## 行动检查表

```markdown
# [场景]检查表

使用时机：

- [ ] 动作或判断问题 1
- [ ] 动作或判断问题 2
- [ ] 动作或判断问题 3

停止条件：
复盘问题：
依据与边界：
```

## 短视频口播稿

适用于抖音或视频号。根据渠道调整语气，不虚构冲突、数据或个人故事。

```markdown
标题：[利益或问题导向]

【0–3 秒】问题或反常识钩子
【3–15 秒】核心观点及出处
【15–45 秒】一个可核验案例或现实应用
【45–70 秒】适用边界与行动建议
【70–90 秒】总结和自然互动引导
```

抖音可更紧凑；视频号可更克制。两者都不以夸张代替证据。

## 小红书笔记

```markdown
标题备选：2–3 个，不使用无法兑现的数字或保证

开头：用户熟悉的场景或问题
冲突：常见做法为什么失效
解释：书中观点、证据和边界
行动：1–3 个可执行动作
结尾：一个具体讨论问题
来源：
```

建议 300–600 字，标签与内容直接相关。

## 朋友圈

控制在 150 字左右：一个观察、一个理由、一个真实行动。没有用户个人经历时使用中性表达，不伪造第一人称故事。

## 公众号文章

```markdown
# 标题

## 一个真实问题
## 书中观点及可靠证据
## 现实应用
## 反例和边界
## 行动清单
## 来源
```

先写 800–1200 字样稿。用户确认角度后再扩写或拆成系列。
